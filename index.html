Selamat Datang di Dunia Internet

Internet merupakan jaringan global yang menghubungkan berbagai perangkat dan jaringan komputer di seluruh dunia.

Melalui website ini, kita akan mempelajari bagaimana internet berkembang, siapa tokoh penting di baliknya, serta bagaimana data dapat dikirim ke seluruh dunia.

Sejarah Perkembangan Internet

Internet berkembang melalui penelitian jaringan komputer selama beberapa dekade. Perkembangannya melibatkan ilmuwan, insinyur, universitas, dan berbagai organisasi.

(1969)

ARPANET

ARPANET mulai menghubungkan komputer di beberapa lembaga penelitian. Pada tahun ini terjadi pengiriman pesan awal melalui jaringan tersebut.

(1974)

Konsep TCP

Vint Cerf dan Robert Kahn memublikasikan rancangan Transmission Control Protocol (TCP).

(1983)

Peralihan TCP/IP

ARPANET beralih menggunakan TCP/IP sebagai protokol komunikasi utama.

(1989)

World Wide Web

Tim Berners-Lee mengusulkan sistem World Wide Web di CERN.

(1991)

Web untuk Publik

World Wide Web mulai tersedia secara lebih luas untuk digunakan masyarakat.

Komponen Pembentuk Internet

Internet terdiri dari berbagai perangkat dan teknologi yang saling terhubung untuk mengirimkan serta menerima informasi.

💻 Komputer / Client

Perangkat yang digunakan pengguna untuk mengakses internet, seperti laptop, komputer, dan smartphone.

📡 Router

Perangkat yang mengarahkan paket data menuju jaringan atau tujuan yang tepat.

🔌 Switch

Perangkat yang menghubungkan beberapa perangkat dalam jaringan lokal (LAN).

🌐 Modem

Perangkat yang membantu menghubungkan jaringan pengguna dengan layanan penyedia internet sesuai teknologi koneksinya.

🖥️ Server

Komputer yang menyediakan layanan, aplikasi, dan data kepada perangkat lain.

🛡️ Firewall

Sistem keamanan yang mengatur lalu lintas jaringan berdasarkan aturan tertentu.

Protokol dan Teknologi Internet

Protokol internet adalah aturan komunikasi yang memungkinkan perangkat saling bertukar informasi melalui jaringan.

🌐 IP Address

IP Address adalah alamat numerik yang digunakan untuk mengidentifikasi perangkat pada jaringan IP.

Contoh: 192.168.1.10

🔎 DNS

DNS menerjemahkan nama domain menjadi alamat IP agar browser dapat menemukan server tujuan.

Contoh: google.com

📦 TCP/IP

Kumpulan protokol komunikasi yang menjadi dasar pengiriman data melalui internet.

TCP dan IP memiliki tugas berbeda.

🌍 HTTP

HTTP adalah protokol komunikasi yang digunakan browser dan server untuk bertukar informasi di Web.

Contoh: http://example.com

🔒 HTTPS

HTTPS adalah HTTP yang dilindungi enkripsi menggunakan TLS sehingga komunikasi lebih aman.

Contoh: https://example.com

Keamanan Internet dan Cybersecurity

Keamanan internet merupakan upaya melindungi perangkat, jaringan, aplikasi, dan data dari akses yang tidak sah serta ancaman digital.

🛡️ Firewall

Firewall mengatur lalu lintas jaringan berdasarkan aturan keamanan untuk membantu mencegah koneksi yang tidak diizinkan.

Contoh: Windows Defender Firewall.

🦠 Malware

Malware adalah perangkat lunak berbahaya yang dirancang untuk mengganggu, merusak, atau menyalahgunakan sistem.

Contoh: virus, worm, dan trojan.

🎣 Phishing

Phishing adalah penipuan yang berusaha membuat seseorang memberikan informasi pribadi melalui pesan atau situs palsu.

Contoh: pesan login palsu.

🔒 Enkripsi

Enkripsi mengubah informasi menjadi bentuk yang tidak mudah dibaca tanpa kunci yang sesuai.

Contoh: enkripsi AES.

🌐 HTTPS

HTTPS melindungi komunikasi antara browser dan server menggunakan TLS.

Contoh: https://example.com

🧰 Antivirus

Antivirus membantu mendeteksi, mencegah, dan menangani perangkat lunak berbahaya.

Contoh: Microsoft Defender.

Tips Menjaga Keamanan Internet

  • Gunakan kata sandi yang kuat dan unik.
  • Aktifkan autentikasi dua faktor (2FA).
  • Perbarui sistem operasi dan aplikasi.
  • Hindari membuka tautan mencurigakan.
  • Unduh software dari sumber resmi.
  • Jangan membagikan kode OTP kepada orang lain.
